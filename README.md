# Uhr lernen

Lern-App zum Uhrlesen für Kinder, optimiert fürs Handy. Eine einzige Datei (`index.html`), keine Abhängigkeiten, läuft offline.

- **Frei**: Zeit über Walzen (oder Zeiger ziehen) einstellen. „Walzen ausblenden“ zeigt dem Kind nur die Analoguhr; Einblenden durch 1,5 s Halten.
- **Uhr lesen**: Die App stellt eine Zeit, das Kind gibt sie über die Walzen ein.
- **Uhr stellen**: Die App nennt eine Zeit, das Kind zieht die Zeiger.
- Stufen: volle Stunde → halbe → Viertel → 5 Minuten → jede Minute → 0–24 Uhr.
- Tageszeit-Anzeige (Mitternacht, Nacht, Morgen, Vormittag, Mittag, Nachmittag, Abend) und optional „Zeit in Worten“.
